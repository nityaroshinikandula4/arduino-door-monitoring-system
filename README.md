# Arduino-Based Door Monitoring System

## Overview
This project is an IoT-based door monitoring system that continuously tracks the status of a door using an ultrasonic sensor and Arduino. It provides real-time alerts based on door activity.

## Features
- Real-time door status monitoring (Open/Close detection)
- Ultrasonic sensor-based distance measurement
- Automated alert system (alarm/notification)
- Low-cost and efficient security solution

## Technologies Used
- Arduino
- Ultrasonic Sensor
- Embedded C / Arduino IDE

## How It Works
- The ultrasonic sensor detects the distance between the door and a fixed point
- If the distance changes beyond a threshold, the system identifies door movement
- Based on the condition, alerts such as alarms or notifications are triggered

## Applications
- Home security systems
- Office monitoring
- Smart IoT-based surveillance

## Outcome
Developed a reliable and cost-effective door monitoring system with real-time response capabilities.
